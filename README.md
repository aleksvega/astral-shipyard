# astral-shipyard

Deterministic generator of astral sailing ships: data in — geometry, budget check, palette, PNG and GLB out. Extracted from the game *Астральный Рубеж* (Astral Frontier), where the same engine builds every hull in the fleet.

Детерминированный движок астральных парусников: фракция, класс, сид и описание словами дают один и тот же борт — геометрию, смету, раскраску, кадр и GLB.

```bash
npm i astral-shipyard three
```

```ts
import { generateShip, createProceduralTextures, parseShipText } from 'astral-shipyard';

const parsed = parseShipText('лигийский галеон, алый, прямые паруса, три мачты');
const ship = generateShip({
  faction: parsed?.faction ?? 'league',
  classId: parsed?.classId,
  seed: parsed?.seed ?? 5,
  blueprint: parsed,                       // плоский разбор: мачты, паруса, краски
  textures: createProceduralTextures(4),   // нужен DOM/Canvas
});

console.log(ship.dna.signature);
```

`parseShipText` и смета работают в чистом Node. Геометрия и карты требуют Canvas: браузер, воркер или `node-canvas`. Для картинок и GLB без браузера есть CLI.

## Зачем это, если есть генераторы кораблей

Соседи (`SpaceshipGenerator`, `sito-ship`, `starship-builder`) делают sci-fi корабли из примитивов. Здесь другое:

- **детерминизм**: один сид — один и тот же меш, подпись и GLB, побитово;
- **фракционные школы**: не палитра, а конструкция — обводы, набор деталей, оснастка;
- **смета**: слоты, типоразмеры, вместимость, масса — сборка либо проходит, либо нет;
- **палитра каналами**: перекрасить борт, не трогая геометрию;
- **посадка по нормали**: накладки и стволы садятся на обшивку, а не висят в воздухе;
- **контракт для агента**: CLI отдаёт JSON с подписью, числом мешей и стволов.

Один красивый корабль лучше сделает одноразовый промт. Флот из двух десятков согласованных бортов, который можно пересобрать по сиду — нет.

## Школы

| Фракция | Школа | Что видно |
|---|---|---|
| Лига | `gondola` | круглый борт, чёрный лак, латунь, веера парусов |
| Империя | `wedge` | гранёная сталь, таран, сопла — и прямые реи под парусами |
| Орки | `scrap` | асимметрия, заплаты, ржавчина, дымные паруса |
| Гоблины | `spike` | шипастый киль, кость, кислотное свечение |
| Нейтралы | `civil` | серый транспорт без прикрас |

## CLI

```bash
npx astral-shipyard --text "гоблинский фрегат, кислотный, три мачты" \
  --out shots/goblin.png --glb shots/goblin.glb --spec shots/goblin.json
```

| Флаг | Смысл |
|---|---|
| `--text` | описание словами (см. словарь ниже) |
| `--faction` | `league` `empire` `ork` `goblin` `neutral` |
| `--class` | `sloop` `frigate` `galleon` `dreadnought` `ram` `crab` |
| `--seed` | целое число |
| `--view` | `three-quarter` `side` `front` `top` |
| `--size` | `1280x800` |
| `--background` | `#0b1224` или `none` |
| `--out` | PNG (обязателен) |
| `--glb` | GLB с запечёнными картами |
| `--tex` | сторона карт в GLB: 1024 по умолчанию, 512/256 — лёгкий файл |
| `--spec` | JSON со блюпринтом и подписью |

Выход — JSON: `ok`, `dna.signature`, `meshes`, `barrels`, `hullColor`, `packUsed`, `glbBytes`, `errors`.

Коды: `0` — годно, `1` — ошибка страницы, `2` — нет аргументов, `3` — нет playwright.

Нужен Chromium: `npx playwright install chromium`.

## Словарь описаний

- Фракция: `лигийский`, `имперский`, `оркский`, `гоблинский`, `нейтральный`.
- Класс: `шлюп`, `фрегат`, `галеон`, `дредноут`, `таран`, `краб`.
- Паруса: `прямые паруса`, `веер`, `без парусов`; `две/три/четыре мачты`.
- Орудия: `две башни`, `два яруса`.
- Краски: `алый`, `ледяной`, `золотой`, `кислотный`, `костяной`, `пустотный`.
- Сид: `сид 42` или `seed 42`.

## Контракты

- **Блюпринт** (`ShipBlueprint`) перекрывает любой автоматический выбор: нос, корма, двигатель, надстройки, паруса, мачты, ярусы, палитра.
- **Смета** (`rulesForScale`, `evaluateBuild`): типоразмер по масштабу, масса, вместимость; ошибка — сборки нет.
- **Палитра** (`applyPalette`): каналы `hull deck trim sail glass core dark lamp wood`.
- **Поверхность** (`probeHullSurface`, `mountFlush`): точка и нормаль обшивки лучом; средняя балка вместо луча запрещена.

## Текстуры

По умолчанию — процедурные canvas-карты (цвет, нормали из высоты, шероховатость). Если положить CC0-сканы и манифест `public/textures/pack.json`, движок подхватит их: см. `public/textures/CREDITS.md`. Нет файлов — тихо работает процедурка.

GLB запекает карты: цвет уходит в JPEG, нормали и шероховатость остаются PNG. Дредноут Империи — 7,7 МБ при `--tex 1024`, 1,7 МБ при `--tex 512`, 8 изображений и 4 материала с картами внутри.
