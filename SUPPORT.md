# Поддержка проекта

Проект открытый (MIT). Деньги идут только на одно: время на текстуры, модели и
движок, чтобы новые борта выглядели как работа художника, а не как заглушка.

## Куда

| Способ | Ссылка | Статус |
|---|---|---|
| GitHub Sponsors | кнопка Sponsor в репозитории | включить в настройках профиля |
| Boosty | ссылка будет здесь | нужно имя аккаунта |
| Карта / СБП | реквизиты по запросу в чате | не публикуются в репозитории |

Публичных реквизитов в коде и документации нет намеренно: их присылают только
по личному запросу, чтобы не кормить мошенников.

## Что это меняет

- Ничего не становится закрытым: поддержка не открывает приватную версию.
- Приоритет задач: сначала то, что просит человек, потом общий бэклог.
- Отчёт о расходе времени — в коммитах и заметках к релизам, без обещаний
  сроков.
